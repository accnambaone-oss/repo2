# Research and claims protocol

For each factual video, distinguish:
- **Verified observation**: source directly documents the claimed event or measurement.
- **Informed interpretation**: cited analysis supports a plausible, qualified explanation.
- **Disputed/uncertain**: include disagreements and limits on screen or narration.
- **Allegory/fiction**: describe as a parable; never present fabricated details as historical evidence.

Before production maintain `research.csv`: claim ID, exact script sentence, URL, author, publication, publish date, access date, evidentiary type, supported/unsupported/uncertain, notes. Prefer primary papers, reports, archives and direct statements. Use no fake source credit; if citations can't be checked, add a visible research-pending banner or make a fictional framing.

## Positive versus harmful application

For genuine social-science explainers, separate “coordination under shared constraints” (constructive) from “engineered scarcity, misinformation, divide-and-rule manipulation” (harmful). Avoid teaching operational social manipulation recipes. Show ethical countermeasures: verify shared information, coordinate on common interests, identify incentive designers, and build alternatives to zero-sum rivalry.
