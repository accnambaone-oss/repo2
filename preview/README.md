The storyboard `visual_demo_storyboard.jpg` was generated from the original SVG engine in `scripts/art.py` and a *reduced-scale* 90-second validation render (180x320, 24fps). The 8-second video is a 360x640 render of the opening scenes with synthesized ambient sound and **NO VOICEOVER**. Both are technical previews, not the user's original video or a production-finished narratively synced film. The actual full 90-second video with visuals+instrumental was also rendered and validated at 180x320 but is not embedded to save package size. To generate a full-resolution (720x1280) version, run `python scripts/render.py examples/divide_trap.json --out out/full.mp4` after installing prerequisites; include `--audio voice.wav` for spoken narration.
